Yahoo!乗換案内

Role
UI Design / Concept Making
Date
2023
Platform
iOS

概要

iOS - Yahoo!乗換案内アプリの交通マップ - トレインキャスト, 運行情報キャストにおいて、デザインコンセプトからデザインリードを行いました。

背景

公共交通での快適な移動をサポートするだけでなく、鉄道ファンや列車に興味を持つお子様などにより楽しんでいただけるよう、2023年8月のサービス開始15周年を記念して、交通マップ - トレインキャスト, 運行情報キャストの企画・デザイン検討を開始しました。

コンセプト

ベンチマークのサービスとして、Flightradar24 を参考し、サービスコンセプトとして、「神の目線で見られる」「オタク心をくすぶる」「現実に即したビジュアライズ」と定義しました。

その後、社員を中心に検討しているサービスコンセプトが本当に刺さるか、具体的にどういうターゲットに使ってもらえそうかなど徹底的に調査し、サービスの核となるターゲットユーザやビジュアルなどの方針を決定していきました。

ターゲットユーザ

調査結果をもとに、コアな鉄道ファンだけではなく、幅広いユーザに使ってもらえる可能性が出てきたため、「鉄道が好き、または趣味として楽しんでいるユーザ」に設定しました。

結果的に老若男女のみなさんにたくさん利用していただくことに繋がりました。

Xのリンク

UI - トップ

眺めるだけでも楽しめるよう、新幹線・有料列車・普通列車の表示有無と現在走行している全国の列車数を表示できます。一目で「日本中でこんなに電車が走っているだ！」と地図からでも数字からでも驚きと感動を提供できることを意識したでUIにしました。

UI - 電車詳細

気になる電車アイコンを選択すると、選択した列車の詳細情報を確認できます。列車情報はもちろん、表定速度や総走行距離、区間平均速度、普段目にすることができない情報も見ることができます。

様々な情報を迷わず確認できるレイアウトを意識しながらUIを設計しました。

UI - 運行情報

全国の列車の遅延や運転見合わせなどの運行情報を地図上で一覧できます。

見ている地図の位置に合わせて、自動でその地域の運行情報を確認できたり、下部のカードを横スワイプするとその路線に合わせて地図表示も最適化するなど、操作性をこだわりました。

電車アイコン

「現実に即したビジュアライズ」というコンセプトのもと、協業したデザイナーに1つ1つ精密に電車のアイコンを作成してもらいました。

地図スタイル

これまでは地下鉄のみ路線カラーだった地図を、JRや私鉄なども含めた地図スタイルにアップデートしました。

路線カラーが増えたことで地図が見づらくならないよう、駅や路線名など公共交通に必要な情報は一目でわかるように、かつ目印となる他施設のピンの色や表示量などをこだわりました。
